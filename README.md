# 🏢 Corporate Myntra Portal

A modern **corporate web portal** built using **React + Vite**, designed to manage business services, MSME schemes, and company-related functionalities in a clean and user-friendly interface.

---

## 🚀 Features

* 🧾 Company Registration & Compliance
* 📊 MSME Schemes & Subsidy Information
* 💼 GST & Income Tax Assistance
* 🏦 Financial & Business Services
* 🌐 Multi-language Support (i18n)
* ⚡ Fast performance with Vite
* 🎨 Clean and responsive UI

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Build Tool:** Vite
* **Styling:** CSS
* **Linting:** ESLint

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/<your-username>/corporate-myntra-portal.git
cd corporate-myntra-portal
```

### 2️⃣ Install dependencies

```
npm install
```

### 3️⃣ Run development server

```
npm run dev
```

👉 App will run on: **http://localhost:5173/**

---

## 📦 Build for Production

```
npm run build
```

---

## 🔒 Environment Variables

Create a `.env` file in root directory:

```
VITE_API_URL=your_api_url_here
```

⚠️ Never push `.env` to GitHub (already ignored)
